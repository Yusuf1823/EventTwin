PROJECT EVENTTWIN - CURRENT CONTEXT & SUMMARY 
====================================================

# 1. PROJECT OVERVIEW
Project Name: EventTwin
Concept: A Digital Twin / Command Center for Mumbai Mega-Events (e.g. Jio World Convention Centre). It uses ML to predict crowd bottlenecks, manage resources, and simulate scenarios.
Tech Stack: React (Vite, TypeScript, Tailwind) for Frontend + Node.js (Express) for Backend + Firebase Realtime Database for state management.

# 2. DEPLOYMENT & ARCHITECTURE (Currently Live)
- BACKEND: Hosted on Render (https://eventtwin.onrender.com). It runs the Express server, connects to Firebase (credentials are securely stored in Render Secret Files), and serves API endpoints like `/api/events`, `/api/alerts`, etc.
- MAIN FRONTEND (Command Center): Hosted on Vercel (https://event-twin-seven.vercel.app). 
- PROXY/CORS SETUP: 
  - The Vercel frontend has a `client/vercel.json` file that proxies all `/api/*` requests to `https://eventtwin.onrender.com/api/*`.
  - The Render backend `server/index.js` has `https://event-twin-seven.vercel.app` added to its CORS `allowedOrigins`.
